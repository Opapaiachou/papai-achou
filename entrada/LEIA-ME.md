# Pasta de entrada

Enquanto a Open API da Shopee não é liberada, suba aqui a planilha (CSV) que o painel de afiliados gera em
**Oferta de produto › marque os produtos › Obter Link**.

Assim que o arquivo chega aqui, o robô roda sozinho: lê os produtos, aplica os filtros e as regras de conteúdo,
manda as melhores ofertas para o seu Telegram e atualiza a vitrine. Depois move a planilha para `processadas/`.
